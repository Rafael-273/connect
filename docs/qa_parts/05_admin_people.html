4. Painel Admin — Pessoas

Acesso: has_admin_access
📈 4.1 — Dashboard Administrativo

/admin-panel/

Fluxo
  1. Login admin/staff → /admin-panel/.
  2. Ver métricas: membros, visitantes, eventos, consolidações, gráficos.
Resultado esperado
  • Métricas corretas; gráficos carregam sem erros.
👥 4.2 — Gestão de Membros (CRUD)

/admin-panel/members/ /admin-panel/members/new/ /admin-panel/members/<id>/edit/

Fluxo
  1. Listar, criar, editar membros.
  2. Soft-delete via /admin-panel/api/delete/.
  3. API JSON: /admin-panel/api/member/<id>/.
Resultado esperado
  • E-mail duplicado rejeitado.
  • Membro deletado não aparece nas listas (soft delete).
🚶 4.3 — Gestão de Visitantes

/admin-panel/visitors/ new/ <id>/edit/

Fluxo
  1. Usuário user_type=visitors ou admin: CRUD de visitantes.
Resultado esperado
  • Usuário sem permissão de visitantes recebe 403.
  • API: /admin-panel/api/visitor/<id>/.
🗺️ 4.4 — Gestão de Bairros

/admin-panel/neighborhoods/

Fluxo
  1. Criar, editar e soft-deletar bairros.
  2. Verificar que aparecem nos selects de cadastro.
🔒 4.5 — Gestão de Usuários

/admin-panel/users/ /admin-panel/users/<id>/reset-password/

Fluxo
  1. Apenas user_type=admin acessa lista de usuários.
  2. Resetar senha → volta para 123.
Resultado esperado
  • Outros roles recebem 403.
  • Login com senha resetada funciona.
