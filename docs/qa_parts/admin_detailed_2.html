6. Admin — Consolidação

admin · superuser · consolidation
📋 6.1 — Lista de Consolidações (Follow-ups)

/admin-panel/followups/ new/ <id>/edit/ delete/

Pré-condição
  • Grupo consolidation, admin ou superuser.
  • Membros com is_available_to_consolidate=True como responsáveis.
  • Template criado (item 6.3).
Fluxo — Criar
  1. Menu Consolidação → Consolidações → Novo.
  2. Selecionar acompanhado, responsável, template, data início.
  3. Salvar — current_week=1.
Fluxo — Listar
  1. Filtrar por nome, responsável, status (ativo/encerrado).
Resultado esperado
  • Aparece em /consolidation/ do responsável.
🔍 6.2 — Detalhe e relatórios

/admin-panel/followups/<id>/detail/ .../report/

Fluxo
  1. Ver acompanhado, responsável, template, semana atual, passos.
  2. Histórico de relatórios do consolidador.
  3. Admin adiciona relatório manualmente se necessário.
📝 6.3 — Templates de Consolidação

/admin-panel/templates/ new/ <id>/

Fluxo
  1. Criar template: nome, descrição, passos semanais (título + orientações).
  2. Duplicar via ?duplicate_from=<id>.
  3. Editar, ver detalhe, excluir.
Resultado esperado
  • Template disponível ao criar follow-up.
📊 6.4 — Relatórios agregados

/admin-panel/reports/

Fluxo
  1. Menu Consolidação → Relatórios.
  2. Dashboard de indicadores espirituais por período.

7. Admin — Escalas de Serviço

admin · superuser (staff)
Fluxo típico: equipes → escala com divisões → dias → escalonar membros → imprimir → membro vê no portal.
🏅 7.1 — Equipes

/admin-panel/teams/ new/ <id>/edit/

Fluxo
  1. Menu Escalas → Equipes.
  2. Criar: nome, ministério, líder, membros.
  3. Filtrar por ministério; editar ou excluir.
📅 7.2 — Criar escala (mensal ou semanal)

/admin-panel/schedules/new/

Fluxo — Mensal
  1. Ministério, título, mês/ano, revezamento de equipes.
  2. Divisões (ex.: Palavra, Recepção) — até 3 níveis.
  3. Orientações gerais; salvar → detalhe da escala.
Fluxo — Semanal
  1. Data início/fim, dias da semana (ex.: quarta, domingo).
  2. Sistema gera ScheduleDay automaticamente no intervalo.
🗓️ 7.3 — Detalhe — dias e membros

/admin-panel/schedules/<id>/

Fluxo
  1. Adicionar dia: .../days/new/ — data, turnos, equipe ou membros.
  2. Editar dia: .../days/<day_id>/edit/.
  3. Atribuir divisões: .../days/<day_id>/divisions/.
  4. Conflito AJAX: /admin-panel/schedules/check-conflict/.
  5. Cancelar dia: .../toggle-cancel/; excluir: .../delete/.
Resultado esperado
  • Membros escalados veem em /schedule/<id>/.
  • Alerta se membro duplicado na mesma data.
📂 7.4 — Divisões hierárquicas

/admin-panel/schedules/<id>/divisions/new/

Fluxo
  1. Criar/editar/excluir divisões (máx. 3 níveis).
  2. Listar por ministério: /admin-panel/ministries/<id>/divisions/.
🖨️ 7.5 — Imprimir / editar / excluir escala

/admin-panel/schedules/<id>/print/ edit/ delete/

Fluxo
  1. Imprimir versão formatada (Ctrl+P).
  2. Editar metadados e divisões; excluir escala (soft delete).
  3. Listar com filtros: ministério, ano, mês, tipo, busca.
