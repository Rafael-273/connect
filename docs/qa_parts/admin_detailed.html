5. Admin — Pessoas e Cadastros

📈 5.1 — Dashboard Administrativo

/admin-panel/

Pré-condição
  • user_type=admin ou is_superuser=True.
Fluxo
  1. Login → redirecionamento para o painel.
  2. Visualizar métricas: membros, visitantes, eventos, consolidações.
  3. Verificar gráficos e indicadores.
Resultado esperado
  • Números batem com as listas; gráficos sem erros JS.
👥 5.2 — Membros (CRUD completo)

/admin-panel/members/ new/ <id>/edit/

Pré-condição
  • admin ou superuser.
Fluxo — Criar
  1. Preencher: nome, e-mail, telefone, bairro, foto, gênero, conversão.
  2. Flags: is_approver, is_available_to_consolidate, is_consolidated.
  3. Definir user_type — cria User + Member (senha padrão 123).
Fluxo — Editar / excluir
  1. Editar dados, vincular cônjuge, alterar flags.
  2. Soft delete via /admin-panel/api/delete/.
  3. API JSON: /admin-panel/api/member/<id>/.
Resultado esperado
  • E-mail duplicado rejeitado; soft delete remove das listas.
  • Flags refletem no portal do membro.
🚶 5.3 — Visitantes

/admin-panel/visitors/

Pré-condição
  • admin, superuser ou user_type=visitors.
Fluxo
  1. CRUD: nome, telefone, bairro, decisão por Jesus, conversão, visita domiciliar.
  2. Visitante com decisão pode ser convertido automaticamente em membro.
🗺️ 5.4 — Bairros

/admin-panel/neighborhoods/

Fluxo
  1. CRUD de bairros; API /admin-panel/api/neighborhood/.
  2. Bairros ativos aparecem nos formulários de cadastro.
🔒 5.5 — Usuários do sistema

/admin-panel/users/ /admin-panel/change-password/

Pré-condição
  • Gestão de usuários: apenas user_type=admin.
Fluxo
  1. Listar usuários; resetar senha → 123.
  2. Trocar própria senha.
