# Imagens do Sítio Filadélfia

Organize aqui somente imagens aprovadas para a campanha:

- `exterior/` — aérea e áreas externas
- `pool/` — área da piscina
- `main-house/` — casa principal
- `game-room/` — salão de jogos e cinema
- `playground/` — parquinho e área esportiva
- `gym/` — academia e salão de festas
- `houses/` — casas de apoio
- `future/` — renders conceituais, sempre identificados como visão de futuro

As fotos disponíveis já estão cadastradas em `website/views/philadelphia_site.py`. Ao adicionar
novas imagens, cadastre o caminho, texto alternativo e categoria no mesmo arquivo.
